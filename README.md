# SCHEINMAN

**Engineering rules taken from public records, applied to real CAD geometry, with every correction
proven by measuring the part again.**

You submit a STEP file of an aluminium plate. The engine measures every hole, judges the
measurements against design rules quoted from FAA guidance, moves the holes that violate a rule,
re-measures the corrected part to prove the fix, and returns a corrected STEP file plus two PDF
reports in which every finding cites its source sentence.

The point is not the four rules it ships with today. The point is the discipline: **no anchor, no
fact.** A number the system cannot trace to an official record, or to its own measurement, does not
reach the report.

```
part.step ─▶ measure ─▶ judge ─▶ correct ─▶ re-measure ─▶ corrected.step
                          ▲                      │          inspection.pdf
                rules quoted from FAA AC         └─ proof   correction.pdf
                severity weighted by FAA
                Airworthiness Directives
```

## What a report looks like

From [`data/reports/plate-edge-close.md`](data/reports/plate-edge-close.md), a demo package
generated by `python -m scheinman.report`:

> **BLOCK: rule R-0001 at hole-1.** Measured `edge_distance_over_diameter` is 1.333, below the
> required minimum of 2. Fatigue cracking originating at fastener holes in 7xxx-series primary
> structure under cyclic loading is documented in service (ADs E7-9396 and 00-4568).
>
> *Scope:* AC 43.13-1B states the 2.0-diameter edge distance for single-row riveted sheet joints.
> This project applies it to every round through-hole … The cited ADs do not state the edge
> distance of the cracked holes …

Each finding carries the verbatim excerpt it rests on, the page it came from, and a **Scope**
paragraph saying where the rule stops being true. The corrected part is then measured again
([`plate-edge-close-correction.md`](data/reports/plate-edge-close-correction.md)).

## How it works

| Stage | Module | What it guarantees |
|---|---|---|
| Measure | [`measure.py`](src/scheinman/measure.py) | Holes, edge distances, pitch and thickness come from the STEP geometry alone (OpenCascade via build123d), in the file's own frame. What it cannot see, it refuses to judge ([`test_measure_honesty.py`](tests/test_measure_honesty.py)). |
| Rules | [`rules.py`](src/scheinman/rules.py), [`data/rules/seed_rules.json`](data/rules/seed_rules.json) | Every threshold carries an anchor; the schema refuses a rule without one at construction time ([`schemas.py`](src/scheinman/schemas.py)). |
| Severity | [`fusion.py`](src/scheinman/fusion.py) | How hard a rule blocks is weighted by documented failures: 94 events fused from FAA Airworthiness Directives. A rule claiming every material and loading can never block: no finite set of events covers an unbounded claim. |
| Verdict | [`verdict.py`](src/scheinman/verdict.py) | A violation is arithmetic over a measurement with a written-down resolution, never a model's opinion. |
| Correction | [`correction.py`](src/scheinman/correction.py) | Moves hole centres to satisfy WARN and BLOCK rules, rebuilds the part where the original was, and re-measures it. Notes are recorded, never enforced. |
| Report | [`report.py`](src/scheinman/report.py), [`paper.py`](src/scheinman/paper.py) | PDF reports where every claim is anchored. |

### Where the rules come from

The vault holds 683 FAA Airworthiness Directives (public Federal Register records) and the FAA
Advisory Circular AC 43.13-1B ([provenance](PROVENANCE.md)). Facts were extracted by two blind LLM
readers working from a closed-vocabulary form, then compared field by field:

- **497 of 507** excerpts are found word for word in the stored record; the 10 that are not
  (paraphrase, elision, table text) are listed by
  [`provenance.py`](src/scheinman/provenance.py) rather than hidden.
- A machine cross-check of 46 AD facts caught all 6 planted decoys
  ([`test_conference_machine.py`](tests/test_conference_machine.py)).
- A human adjudicated 13 handbook facts and found none invented. Thirteen is a small sample: it bounds
  the true invention rate only loosely, and the pages say so.

### The web counter

A single Cloudflare Worker ([`web/src`](web/src)) serves the pages and the API: password gate with
HMAC-signed tickets and a serialised attempt counter, Turnstile anti-bot check, upload validation,
job state in a Durable Object, a watchdog that declares stalled jobs dead, and an alarm. The CAD
kernel cannot run in a Worker, so the engine runs on GitHub Actions
([`analyze.yml`](.github/workflows/analyze.yml)), dispatched per part, and calls back with the
delivery.

## Run it

Requires Python 3.12, [uv](https://docs.astral.sh/uv/) and Node 22.

```bash
uv sync --locked

# Generate two sample parts, then run one end to end
uv run python -c "from pathlib import Path; from scheinman.webbuild import write_samples; write_samples(Path('samples'))"
uv run python -m scheinman.job samples/bracket-sample.step out --material-series 7xxx --loading cyclic
# out/ now holds the corrected STEP, the two PDF reports and result.json
```

## Verify it

```bash
./check.sh
```

One command, the same one CI runs on every push: `ruff format`, `ruff check`, `mypy --strict`,
the Python suite (204 tests), a guard that no stored secret appears in the repository, and the
Worker's Node suite (69 tests). It needs no secrets and no network beyond installing dependencies.

## Engineering principles

- **No anchor, no fact.** Three kinds of anchor exist: a canonical citation, a literal excerpt from
  a Directive, or the system's own measurement ([`schemas.py`](src/scheinman/schemas.py)).
- **A blank is honest.** A field the source does not state stays empty; a guessed value would be an
  invention.
- **Visible text is a claim.** The pages are tested against the code, the same as a number in a
  report ([`test_webbuild.py`](tests/test_webbuild.py)).
- **Every incident becomes a check.** [`LESSONS.md`](LESSONS.md) lists 32 incidents, each with the
  test that now prevents it. Code comments cite them by number.
- **One source of truth.** Shared values live in
  [`ecosystem/CONTRACTS.md`](ecosystem/CONTRACTS.md), and tests bind that page to the Python and
  JavaScript code, so drift breaks the build.

## Limits, stated plainly

- Four rules, from one passage of one Advisory Circular, applied to flat plates with round
  through-holes. The architecture is general; the rule base is not yet.
- The correction moves hole centres within the plate. It knows nothing about mating parts or
  tolerances, so the output is a proposal for an engineer, not a released drawing.
- Extraction was run in interactive model sessions. Their outputs are stored and replayed by the
  tests; they cannot be reproduced bit for bit.
- The live prototype runs behind a password. Access on request.
